## Dataset Used

The primary dataset is `student-por.csv`, containing 649 student records
and 33 variables from a Portuguese language course.

The `student-mat.csv` dataset is retained as supplementary raw data.
It is not directly combined with the Portuguese dataset because 382
students appear in both datasets.

The official variable descriptions are retained in
`data/raw/student.txt`.
